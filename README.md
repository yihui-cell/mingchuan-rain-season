# 明川·雨季

> 同一座明川，同一场雨，两段人生。
> 一个用 HTML/CSS/JS 手写的视觉小说（galgame）系列 —— 没有引擎依赖，单个 HTML 文件就能玩。

---

## 系列结构

| | 第一作 | 第二作 |
|---|---|---|
| 标题 | **雨落有声**<br>Rain Has a Voice | **雨落无声**<br>Rain Has No Sound |
| 主角 | 沈知微（建筑系大三）× 江砚（体育系大四） | 艾青（水利系学姐 22）× 你（第一人称，可改名） |
| 时长 | 约 90 分钟 | 约 2 小时 |
| 结局 | 1 主 + 1 通常 + 5 隐藏 = **7** | 1 好 + 1 坏 + 2 隐藏 + 1 通常 = **5** |
| 数值 | G 距离 / T 信任 / W 自我 | H 好感 / X 信任 / Z 真心 |
| 主题 | 表面在攻略他，其实在攻略她自己 | 系统要你刷好感，后来你忘了那本来是个任务 |

两作**软联动**：各自独立通关，彩蛋互相点亮。

## 直接玩（不用装任何东西）

打开 `dist_series/index.html` —— 那是系列入口页，两作都挂在下面。

或者单独打开：

- `dist_series/rain1.html` —— 第一作《雨落有声》
- `dist_series/rain2.html` —— 第二作《雨落无声》

**这三个文件是完全自包含的**：剧情数据、立绘、背景图全部以 base64 内联，双击就能在浏览器里玩，断网也行。手机上打开同样可以玩。

## 引擎设计

没有用任何游戏引擎，就是一个 HTML 文件里的一套**状态机 + 数据驱动**：

```
advance()  ←  唯一推进入口（点击 / 空格 / 回车都走它）
   │
   └─ mode: playing | choice | ending | wait | idle
```

剧情是纯数据，节点类型：

| 节点 | 含义 |
|---|---|
| `nar` / `think` | 旁白 / 主角内心独白 |
| `say` | 对白（`who` 指定说话人） |
| `sys` / `sysbox` | 系统台词 / 系统弹窗（需要玩家点掉） |
| `show` | 切换立绘表情 |
| `scene` | 切换场景背景 |
| `eff` | 演出效果（闪白 / 震屏） |
| `big` | 大字幕 |
| `cg` | 全屏 CG |

结局按**优先级数组**取第一个满足条件的，并留一个 `cond: () => true` 的兜底结局保证不会有死路。

### 数值配平

两作的选项数值都做过**穷举验证**（第一作 259,200 种组合，第二作 17,496 种），确认：

- 没有任何组合落空（`未命中 = 0`）
- 每一个结局都真实可达
- 数值增益总分控制在 0–100 以内，避免撞上限后失去区分度

第二作的最终分布：

```
隐藏① 他不是第一个   4.6%
隐藏② 另外三个人     1.8%
好结局 雨落有声      24.1%
坏结局 转学          25.8%
通常结局 各自的天晴   43.7%
```

## 自己打包

```bash
python build_series.py      # → dist_series/ （两作 + Hub）
python build_single.py      # → 雨落有声_单文件.html + dist/
```

打包脚本会把 `story_data.js` 内联、把所有图片转成 base64 data URI，最后断言**没有任何残留的 `assets/` 引用**（防止单文件版裂图）。

---

## 配图产线

- **场景 / 背景** → 文生图，日系动画风实景
- **角色立绘** → **图生图**保人物一致（传已有立绘 + 高保真），只改神态
- **后处理** → `new/tools/process_assets.py`：裁掉生成图右下角水印 + 白底 flood-fill 抠透明

## 兼容性

- 桌面端与现代移动端浏览器（Chrome / Edge / Safari / Firefox）
- 移动端已适配：`100dvh` 动态视口、`env(safe-area-inset-*)` 刘海安全区、`touch-action:manipulation` 去点击延迟
- 存档与结局图鉴用 `localStorage`（系列统一前缀 `mingchuan_`）
